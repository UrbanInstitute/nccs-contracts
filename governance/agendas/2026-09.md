## Proposals (chair)

5. **Dataset designations: add a "peripheral" tier.** Charter §3
   currently distinguishes essential infrastructure from
   out-of-scope special projects only. Proposal: a three-way
   designation — essential / peripheral (actively archived, not
   curated or validated; e.g. the raw e-file XML archive, 990-N
   postcards) / project or external data (disseminated, not
   governed). Charter amendment if adopted.
6. **Rule hierarchy labels.** Tag charter clauses as principle
   (aspiration) / guidance (target, not monitored) / requirement
   (enforced, contract-grade), so the document can stay detailed
   while the set of hard requirements stays narrow. Applied as
   labels on existing text, not a rewrite. Charter amendment if
   adopted.
7. **Versioning sub-questions (§5 footnotes).** Three small calls:
   - first release of a wave: patch `00` or `01`?
   - stable assets (e.g. crosswalks): fixed wave designation?
   - is `A = 00` the marker for beta/experimental series?
8. **Geocoded address history (BACKLOG Z15).** Proposal to geocode
   the historical address spells in the address-resolved crosswalk
   so it carries tract identifiers directly. Brought as a §8
   prioritization exercise: named user (Columbia doctoral
   researcher tracking NY neighborhood organizations year-to-year;
   we committed 2026-08-24 to notify her when it ships), augments
   essential infrastructure, bounded marginal work (spell-0
   geocodes join back from the geocoded Unified BMF; the rest
   dedupes before geocoding). Decision to route: companion table
   vs new columns on the crosswalk. ADR to follow if adopted.
9. **Per-dataset policy blocks.** Extend the contract YAML schema
   with governance fields: collection/release cadence, protected
   variables, join keys, controlled vocabularies, privacy handling,
   allowable uses. Decision record if adopted.

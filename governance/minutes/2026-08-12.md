# Governance committee — minutes, 2026-08-12 (first meeting)

**Present:** Thiya Poongundranar (chair), Jesse Lecy, Lewis Faulk
(first ~25 min), Erika Tyagi. ~40 minutes.

## Decisions

1. **Scope and vocabulary (charter §3).** The "990 panel family" is
   adopted as shared vocabulary for the related products — NCCS CORE
   (PZ/PC/PF), SOI extracts, e-file panels, 990-N postcards — which
   remain SEPARATE registry entries (the e-file panels are siblings
   of, not part of, the CORE product). Governed scope also includes
   BMF, geographic crosswalks, and metadata tables.
   Special projects (trends survey, political-activity data) are
   outside governance unless elevated. The e-file v2_x datasets join
   the contract registry.
2. **Essential fields (charter §3).** Test: anything whose change
   breaks downstream dependencies (JL). Includes org identifiers /
   join keys (EIN2, ein_raw, affiliation, classification), tax
   period with explicit fiscal/tax/filing-year definitions (LF),
   geographic definitions incl. Census vintage, sanitized addresses,
   NTEE.
3. **Versioning (charter §5).** Three-tier `vA.W.P` adopted, with
   filenames carrying `_{YYYY_MM}` for the raw-data period (version
   says what changed; date says data-as-of-when).
4. **Release flow (charter §6).** Producers send a one-paragraph
   plain-language heads-up when a new build ships; NCCS generates
   manifests, release notes, and catalog updates. Policies are
   progressive ("aspirational, not enforced all at once" — JL),
   structure agreed.
5. **Patches (charter §5).** e-file bug fixes overwrite the same
   endpoint; both versions archived. Embedded version/receipt column
   under design.
6. **Retention (charter §7).** Keep every version (waves and
   patches); tier old versions to cheaper storage (ET); expose only
   the latest of a wave publicly; 90-day windows for renames.
7. **Priorities (charter §8).** Order ratified: existing users >
   augmenting infrastructure > demonstrated demand. NODC operates as
   the experimental/R&D layer; proven tools considered for NCCS
   integration. Breadth-vs-depth and super-user-vs-new-user weighting
   deferred to the strategy conversation with Laura.
8. **Cadence.** Standing monthly 30-minute check-in; quarterly
   deeper session.
